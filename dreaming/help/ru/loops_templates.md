## Зачем этот раздел

Шаблоны loops — каталог заготовок, из которых создаются reflex-loop-ы. Это
единственный раздел приложения с полноценным редактированием: шаблон можно
создать, изменить и удалить прямо здесь.

## Откуда берутся данные

Из каталога `loops_templates_dir`. Если он не задан, берётся
`<working_dir>/.claude/loops/templates`.

Шестнадцать стартовых шаблонов кладутся автоматически при первичной настройке
проекта. Всё, что сверх них, добавляете вы.

## Что на экране

Список шаблонов. Клик открывает форму редактирования.

Поля шаблона:

| Поле | Что это |
|---|---|
| **slug** | Идентификатор и имя файла. Только строчные латинские буквы, цифры и дефис; первый и последний символ — буква или цифра. |
| **name** | Человекочитаемое название. Если пусто, подставится slug. |
| **description** | Для чего этот шаблон. |
| **engine** | Движок исполнения, по умолчанию `loop`. |
| **preset** | Предустановка, если движок её поддерживает. |
| **max_iterations** | Ограничение на число проходов. Пусто — без ограничения. Нечисловое значение молча превращается в «без ограничения». |
| **tags** | Метки через запятую. |
| **team** | Команда агентов, по умолчанию `auto`. |
| **body** | Тело шаблона — собственно инструкция. |

Шаблон сохраняется как markdown-файл с YAML-фронтматтером: поля выше — это
фронтматтер, `body` — текст под ним.

## Что можно сделать

- **Создать шаблон** — форма нового шаблона.
- **Изменить** — открыть существующий и сохранить.
- **Удалить** — убрать файл шаблона.

Сохранение по существующему slug перезаписывает шаблон. Отдельного
подтверждения на этот случай нет, так что менять slug у существующего
шаблона — это создать второй, а не переименовать первый.

## Связь с другими разделами

- **Reflex Loops** — сами loop-ы, созданные из этих шаблонов.

## Если что-то не так

- **Написано, что каталог не настроен** — задайте `loops_templates_dir` в
  настройках проекта либо убедитесь, что у проекта задан рабочий каталог,
  от которого строится путь по умолчанию.
- **Не сохраняется, ругается на slug** — в нём есть заглавные буквы,
  подчёркивания, пробелы или он начинается либо заканчивается дефисом.
- **`max_iterations` не сохранилось** — введено не число; поле молча стало
  пустым, то есть «без ограничения».
- **Список пуст на новом проекте** — первичная настройка не проходила.
  Нажмите настройку одной кнопкой на дашборде.
